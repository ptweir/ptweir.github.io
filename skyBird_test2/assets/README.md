# SkyBird Game Assets

This directory contains all the game assets for SkyBird.

## Directory Structure

- `images/` - Game sprites, backgrounds, and UI elements
- `icons/` - App icons and favicons
- `sounds/` - Audio files (moved to root/sounds/ for organization)

## Recommended Assets

### Images
- `bird-sprite.png` - Bird character sprite sheet
- `pipe.png` - Pipe obstacle sprite
- `background.png` - Game background
- `cloud.png` - Cloud sprites
- `ground.png` - Ground texture

### Icons
- `favicon.ico` - Browser favicon
- `icon-192x192.png` - App icon for mobile devices
- `icon-512x512.png` - Large app icon

### Audio (in /sounds/ directory)
- `jump.mp3` - Bird jump sound
- `score.mp3` - Score increment sound
- `hit.mp3` - Collision sound
- `background.mp3` - Background music (optional)

## Image Specifications

- **Bird**: 40x30px (or multiples for high-DPI)
- **Pipes**: 60px wide, variable height
- **Icons**: Standard web app icon sizes (192x192, 512x512)
- **Format**: PNG for images with transparency, JPG for backgrounds

## Audio Specifications

- **Format**: MP3 or OGG for web compatibility
- **Quality**: 44.1kHz, 16-bit for sound effects
- **Size**: Keep files small for mobile performance
